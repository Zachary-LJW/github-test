第一节
路径与目录
0. Linux 终端的默认规则

Linux 终端里输入的命令，默认都是在“当前目录”里执行。

当前目录：
current working directory

意思就是：
你现在所在的文件夹位置。

1. ls：list，列出当前文件夹里的东西

对于文件夹来说，ls 就是列出当前目录里面的文件和文件夹。

ls -l：
可以理解为 long format，长格式，会显示更详细的信息。

例如：
drwxr-xr-x 2 ubuntu ubuntu 4096 May 27 Desktop
-rw-r--r-- 1 ubuntu ubuntu 120 May 27 test.txt

开头是 d 的，通常是目录/文件夹。
开头是 - 的，通常是普通文件。

2. pwd：print working directory

作用：
查看当前位置。

简单理解：
我现在在哪？


3. cd：change directory

作用：
切换目录。

cd ..
回到上一级目录。

注意：
cd 和 .. 中间要有空格。
cd.. 是错误写法，可以记成反面例子。

.. 代表上一级目录。

cd ~
回到 home 目录。

~ 表示 home directory，也就是用户主目录。


4. mkdir：make directory

作用：
创建文件夹/目录。

mkdir test

意思就是：
在当前目录创建一个叫 test 的文件夹。

重点：
mkdir 创建的位置取决于你现在在哪。
不确定位置时，先用 pwd 看一下。


第二节
Linux 文件操作
1. touch：创建空文件

touch note.txt
意思是创建一个叫 note.txt 的空文件。


2. cat：查看文件内容

cat note.txt
意思是显示 note.txt 里面的内容。


3. echo：输出文字

echo "hello linux"
意思是在终端显示 hello linux。


4. >：覆盖写入文件

echo "hello" > note.txt
意思是把 hello 写进 note.txt。
如果 note.txt 原来有内容，会被覆盖。


5. >>：追加写入文件

echo "second line" >> note.txt
意思是在 note.txt 后面追加一行内容。
不会覆盖原来的内容。


6. cp：copy，复制文件

cp note.txt backup.txt
意思是复制 note.txt，生成 backup.txt。


7. mv：move，移动或重命名

mv backup.txt old_note.txt
意思是把 backup.txt 改名成 old_note.txt。

mv note.txt lab1/
意思是把 note.txt 移动到 lab1 文件夹里。


8. rm：remove，删除文件

rm old_note.txt
意思是删除 old_note.txt。

注意：
rm 比较危险，删除前最好先 ls 看清楚。

第三节
路径 Path
1. path：路径

路径就是文件或文件夹的位置。


2. absolute path：绝对路径

从根目录 / 开始写的完整路径。

例子：
/home/zachary/linux-practice/note.txt

特点：
一定以 / 开头。


3. relative path：相对路径

从当前目录开始找。

例子：
cd linux-practice

如果当前就在 /home/zachary，那么 linux-practice 就是相对路径。


4. . 和 ..

. 表示当前目录。

例子：
./script.sh
意思是运行当前目录下的 script.sh。

.. 表示上一级目录。

例子：
cd ..
意思是回到上一级目录。


5. wildcards：通配符

* 匹配任意多个字符。

例子：
ls *.txt
列出所有 .txt 文件。

? 匹配任意一个字符。

例子：
ls ?.txt
匹配 a.txt、b.txt 这种只有一个字符名字的 txt 文件。

[abc] 匹配 a、b、c 中的一个字符。

例子：
ls [abc].txt


6. rmdir

rmdir test
删除空目录。

如果目录里面有文件，rmdir 会失败。


7. rm -r

rm -r test
删除目录和里面的内容。

-r 可以理解为 recursive，递归。


8. rm -rf

rm -rf test
强制删除目录和里面的内容。

-r：recursive，递归
-f：force，强制

注意：
rm -rf 很危险，不要乱用。

第四节
Linux权限 permission
1. ls -l 可以查看权限

例子：
-rw-r--r-- 1 zachary zachary 120 May 27 test.txt
drwxr-xr-x 2 zachary zachary 4096 May 27 lab1


2. 第一个字符表示类型

d  目录/文件夹

rw-   r--   r--

x：可以运行这个文件


6. 目录里的权限

w：可以在目录里创建/删除文件

7. chmod

作用：
修改权限。

例子：
chmod +x test.sh

意思：
给 test.sh 增加执行权限。


8. ./test.sh

. 表示当前目录。

./test.sh

意思是：
运行当前目录下的 test.sh。


9. sudo

sudo 可以理解为用管理员权限执行命令。

例子：

注意：
sudo 权限很高，不要乱用。

第五节
Bash脚本入门

1. Bash script

Bash script 就是把很多 Linux 命令写进一个 .sh 文件里，然后一次运行。

简单理解：
脚本 = 自动执行命令的文件。


2. .sh 文件

脚本文件通常用 .sh 结尾。

例子：
hello.sh

#!/bin/bash

作用：
告诉 Linux 这个脚本用 bash 来运行。


4. echo

echo 用来输出文字。

例子：
echo "Hello Linux"


5. 运行脚本

方法 1：
bash hello.sh

方法 2：
chmod +x hello.sh
./hello.sh


6. 变量 variable

变量就是用一个名字存一个值。

例子：
name="Zachary"
echo $name

注意：
等号两边不能有空格。

正确：
name="Zachary"

错误：
name = "Zachary"


7. 使用变量

echo "Hello $name"

更清楚的写法：
echo "Hello ${name}"


8. read

read 用来读取用户输入。

例子：
read name

常用写法：

9. comment 注释

# 后面的内容是注释，不会执行。

例子：
# This is a comment

10. Bash 变量写法注意

正确取变量值：

$name
${name}

例子：
name="Zachary"
echo "Hello $name"
echo "Hello ${name}"

输出：
Hello Zachary


错误写法：

$(name)

原因：
$(name) 在 Bash 里不是取变量，而是执行 name 这个命令。

所以如果写：

echo "Hello $(name)"

Bash 会把 name 当成命令去找。
如果系统里没有 name 这个命令，就会报错：

name: command not found


记忆：

$name        取变量 name 的值
${name}      取变量 name 的值，更清楚
$(name)      执行 name 这个命令，错误示范

第六节

1. if 条件判断

作用：
根据条件决定执行哪段代码。

基本结构：

if [ 条件 ]; then
    命令
fi

if 开头，fi 结尾。


2. if else

if [ 条件 ]; then
    条件成立时执行
else
    条件不成立时执行
fi


3. if elif else

if [ 条件1 ]; then
    命令1
elif [ 条件2 ]; then
    命令2
else
    默认命令
fi


4. 判断字符串

=   等于
!=  不等于
-z  字符串为空
-n  字符串不为空

例子：
if [ "$choice" = "fruits" ]; then


5. 判断数字

-eq  等于
-ne  不等于
-gt  大于
-lt  小于
-ge  大于等于
-le  小于等于

例子：
if [ "$num" -gt 0 ]; then


6. Bash 条件判断最容易错的地方

[ ] 里面要有空格。

正确：
if [ "$choice" = "fruits" ]; then

错误：
if ["$choice"="fruits"]; then


7. 记忆

if：如果
elif：否则如果
else：否则
fi：结束 if

8. 输出 $ 符号时要注意

在 Bash 里，$ 有特殊含义，表示取变量值。

所以如果只是想输出美元符号 $，要写成 \$。

例子：
echo "Meat usually costs around \$10-\$20 per kg."

输出：
Meat usually costs around $10-$20 per kg.

错误写法：
echo "Meat usually costs around $10-$20 per kg."

原因：
Bash 会把 $10 和 $20 当成变量/参数去解析，可能导致输出不对。

另一种写法：
echo 'Meat usually costs around $10-$20 per kg.'

单引号里面的 $ 不会被解析。

case "$变量" in
    选项1)
        命令
        ;;
    选项2)
        命令
        ;;

        ;;
esac


5. case 关键点

case 开头
esac 结尾
;; 表示一个选项结束
*) 表示其他所有情况

常用于：

第17节
process states 和 PCB
1. process state

process state = 进程当前处于什么阶段。


2. 五个常见状态

New：
刚刚被创建。

Ready：
准备好运行，正在等 CPU。

Running：
正在 CPU 上执行。

Blocked / Waiting：
暂时不能运行，因为在等某件事，比如 I/O。

Exit：
进程结束。


3. 常见状态转换

New → Ready：
进程创建完成，进入等待队列。

Ready → Running：
CPU 选中它，开始执行。

Running → Ready：
时间片用完，回去排队。

Running → Blocked：
运行时需要等待 I/O 或事件。

Blocked → Ready：
等待的事情完成，重新准备运行。

Running → Exit：
程序执行结束。


4. PCB

PCB = Process Control Block

意思：
进程控制块。

简单理解：
PCB 是操作系统给每个进程准备的档案卡。


5. PCB 里面常见信息

PID
process state
priority
program counter
registers / context data
memory information
I/O information


6. PCB 的作用

保存进程信息。

让进程被暂停后，之后还能恢复继续运行。


7. Context Switch

Context Switch = 上下文切换。

意思：
CPU 从一个进程切换到另一个进程。

过程：
保存旧进程状态到 PCB
读取新进程 PCB
运行新进程
