Round 5 Notes

1. pwd

pwd means print working directory.
It shows the current directory.


2. ls

ls lists files and folders in the current directory.


3. ls -l

ls -l lists files and folders in long format.


4. mkdir

mkdir creates a directory.

Example:
mkdir exam


5. cd

cd changes directory.

Examples:
cd exam
cd ..
cd ~

cd exam:
enter the exam directory

cd ..:
go to the parent directory

cd ~:
go to the home directory


6. touch

touch creates an empty file.

Example:
touch notes.txt


7. cat

cat displays the content of a file.

Example:
cat notes.txt


8. cp

cp copies a file.

Example:
cp notes.txt backup.txt


9. mv

mv moves or renames a file.

Example:
mv backup.txt old.txt

This renames backup.txt to old.txt.


10. rm

rm removes a normal file.

Example:
rm old.txt


11. rmdir

rmdir removes an empty directory.

Example:
rmdir testfolder


12. rm -r

rm -r removes a non-empty directory.

Example:
rm -r project


13. > redirection

> overwrites old content.

Example:
echo "Hello Linux" > notes.txt

This writes Hello Linux into notes.txt.
If notes.txt already has content, it will be overwritten.


14. >> redirection

>> appends new content.

Example:
echo "CST206 is useful" >> notes.txt

This adds CST206 is useful to the end of notes.txt.
It does not overwrite old content.


15. wc -l

wc -l counts lines.

Example:
wc -l notes.txt

This outputs the number of lines and the filename.


16. wc -l < file

Example:
wc -l < notes.txt

This counts the number of lines in notes.txt.
Because of <, only the number is printed, not the filename.


17. pipe |

| sends the output of the left command to the input of the right command.

Example:
cat students.txt | grep "CST206"


18. grep

grep searches for text in a file.

Example:
grep "CST206" students.txt

This prints lines that contain CST206.


19. grep -i

-i means ignore case.

Example:
grep -i "cst206" students.txt

This can match CST206, cst206, or Cst206.


20. grep + wc -l

Example:
grep "CST206" students.txt | wc -l

This counts how many lines contain CST206.


21. head

head shows the first lines of a file.

Example:
head -2 students.txt

This shows the first 2 lines.


22. tail

tail shows the last lines of a file.

Example:
tail -2 students.txt

This shows the last 2 lines.


23. Important mistakes

Wrong:
wc -l

Correct:
wc -l notes.txt

Reason:
wc -l alone waits for keyboard input.
To count lines in a file, give the filename.


24. Difference between > and >>

> means overwrite.
>> means append.


25. Difference between rm, rmdir, and rm -r

rm file.txt:
removes a normal file

rmdir folder:
removes an empty directory

rm -r folder:
removes a non-empty directory
